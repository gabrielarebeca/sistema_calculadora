# 🧮 Sistema Calculadora

Projeto de uma **calculadora simples** desenvolvida em **C#**, utilizando **Windows Forms** para criar uma interface gráfica amigável. O sistema permite realizar operações matemáticas básicas com praticidade.

## 📌 Sobre o Projeto

Este projeto tem como objetivo apresentar uma calculadora funcional com interface gráfica, ideal para aprendizado e prática de desenvolvimento com C# e Windows Forms.

## ⚙️ Funcionalidades

- ✅ Interface gráfica com botões interativos  
- ➕ Operações: Adição, Subtração, Multiplicação e Divisão  
- 🧼 Botão "C" para limpar a entrada

## 🛠 Tecnologias Utilizadas

- **C# (.NET Framework)**
- **Windows Forms (WinForms)**
